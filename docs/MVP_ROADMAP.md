# LifeOS — MVP Roadmap

## Phase 0: Software-First MVP

**Goal**: Validate that users want AI memory assistant, no custom hardware needed.

### Build Order
1. Audio upload pipeline (iPhone → backend)
2. Transcription (Whisper API)
3. Event segmentation (Claude)
4. Daily summary generation
5. Meeting summary cards
6. Ideas extraction
7. Calendar suggestions
8. Notes export
9. Semantic search
10. Coaching layer

### What's In
- iPhone app with record + upload
- Backend transcription pipeline
- AI event segmentation
- Daily summaries with coaching
- Idea / meeting / task feeds
- Memory search
- Privacy controls (retention, encryption, consent modes)

### What's Out (for now)
- Custom wearable hardware
- Apple Watch app
- CRM integrations
- Slack/WhatsApp integrations
- Relationship memory graph
- Long-term behavior analytics
- AI-generated follow-up messages

### Success Criteria
- Users record 30+ min/day
- Daily summary open rate > 60%
- 5+ ideas saved per week per user
- Meetings processed with useful summaries
- Users report "forgetting less"
